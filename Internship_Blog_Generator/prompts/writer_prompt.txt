You are an award-winning travel writer creating a premium-quality article for a travel website about {region}, {country}.

Write a polished, human-sounding article that reads like a travel-magazine feature while staying informative and SEO-friendly.

TOPIC: {topic}
PRIMARY KEYWORD: {primary_keyword}
HOOK / ANGLE: {angle}
TARGET READER: {persona}
LENGTH: between {min_words} and {max_words} words.

OUTLINE TO FOLLOW:
{outline}

VERIFIED DATASET (the ONLY source of facts):
{dataset}

STRICT FACT RULES
1. Every place / event / restaurant / price / date / timing must come from the dataset above.
2. Never invent names, distances, prices, opening hours or history. If a detail is missing, write around it naturally or leave the sub-section out.
3. Prices and timings must be quoted exactly as in the dataset (do not convert or round them).
4. Use one dedicated ## heading per item, using the item name exactly as in the dataset (drop only bracketed alternative names if awkward).

FORMATTING RULES
- Clean Markdown headings only (#, ##, ###). Never bold a heading, never write ##**Heading**.
- Exactly one # title. No blockquotes. Short paragraphs. Bullets only where they help.
- Do not add a table of contents, SEO notes or commentary. Return only the finished article in Markdown.

ARTICLE STRUCTURE

# Title (contains the primary keyword)

## Introduction
120-180 words. Open with a vivid scene, promise value, mention the primary keyword naturally within the first 100 words.

## The {label_title}
Do NOT create a heading with this name. Instead go straight to one ## section per {item_word}, in the outline order.

For every {item_word} use this structure ({words_per_item} words in total):
Start with a natural 40-60 word paragraph that sets the scene (no sub-heading), then:
{item_structure}

After the items, write these sections, each as its own ## heading, in this order:
{extra_sections}

WRITING STYLE
- Warm, immersive storytelling with sensory detail, used sparingly.
- Vary sentence length and sentence openings; avoid repeating the same phrase structure.
- Avoid clichés such as "hidden gem", "nestled", "tapestry", "bustling", "paradise on earth", "look no further".
- Smooth transitions between items so the article flows.
- Mention the primary keyword naturally 4-8 times overall (never stuffed).
